## Important data note

The current backend generates demo estimates from a model trained on synthetic data. It does **not** fetch live pollution readings, real weather, or official AQI measurements. The results should not be used for health, travel, or emergency decisions.

## Run locally

1. Extract the ZIP file.
2. Open the extracted `Z-B-R-E-A-T-H-E` folder in PyCharm.
3. Open the Terminal panel in PyCharm.
4. Install dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Start the app:

   ```bash
   python app.py
   ```

6. Open `http://127.0.0.1:5000` in your browser. Keep the terminal open while using the site.

## Deploy with Render

1. Upload the files and folders inside this project to a GitHub repository.
2. In Render, create a new **Web Service** connected to that repository.
3. Use these settings if Render does not fill them automatically:
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:** `gunicorn app:app`
   - **Health check path:** `/health`
4. Deploy and wait for the build to complete.

Render will provide a public URL if deployment succeeds.

## Known limitations

This is a demonstration project. Estimates are generated by the current model and are not verified live AQI measurements. Connect a trusted real-time data source before presenting results as current pollution readings.
